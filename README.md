### ReadMe

**TXT·EPUB 파일을 관리하고 읽으며, AI 분석과 추천으로 다음 읽을거리를 찾는 독서 앱**

- **앱:** 파일·폴더 관리, 독서 위치 저장·복원, 본문 검색과 검색 위치 이동
- **AI 기능:** Gemini 기반 장르·키워드·요약 생성, 분석 결과 조회·수정
- **서버:** 파일·독서 API, 분석 상태 관리, 장르·키워드 기반 추천
- **주요 설계:** 중복 분석 제어, 분석 결과와 독서 상태의 갱신 범위 분리, 인증 요청의 토큰 재발급 공유

`TypeScript` `React Native` `Expo` `Java` `Spring Boot` `PostgreSQL` `Gemini API`
